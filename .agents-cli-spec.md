# Daily Top News Summary AI Agent Specification

This project implements an automated AI agent built with the Google Agent Development Kit (ADK).

## Core Capabilities
1. **Interactive Onboarding**: Collects and validates email addresses (RFC 5322) and thread-safely normalizes IANA timezones and standard aliases (`EST`, `PST`, `IST`, `JST`).
2. **DST-Aware Scheduling**: Computes local 8:00 AM delivery times pre-converted to UTC and handles DST transitions smoothly.
3. **Grounded News Search**: Uses `NewsResearcherAgent` with date cutoff filters to fetch verified news from the past 24 hours in user-local time.
4. **Deterministic HTML Rendering**: Converts Markdown digests into clean, sanitized HTML email templates using `nh3`/`markdown`.
5. **Resilient Dispatch & Failure Handling**: Features atomic Firestore claim transactions, bounded stale lock cleanups (`.limit(50)`), SendGrid HTTP error diagnostics, and automatic status release upon failure.
